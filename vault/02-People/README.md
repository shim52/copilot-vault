# 02-People — one page per person

Create pages from `99-Templates/Person.md`, named exactly as you'd write the `[[wikilink]]` (first name is fine if unambiguous).

What the daily pass uses on each page:
- `Email:` — to match calendar attendees to the page (match is on the local part before `@`, so domain changes don't break it).
- `pronouns:` frontmatter — never infer pronouns from a name.
- `## 📦 Open items` — everything you're tracking for this person: things you owe them, things they owe you, topics to raise. **Every** unchecked item is seeded into your next 1-1 prep with them. Only you tick them.
- `## 🗂️ Meetings` — the pass prepends a link to each new session note.

Start with your manager ([[{{MANAGER_NAME}}]]) and your team.
